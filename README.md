# Scopone Scientifico (offline web app)

Play Scopone Scientifico against three AI levels, entirely in the browser: Pulcino (easy), Volpe (medium), Leone (hard).
No server, no account; after the first load it works offline.

**iPhone/iPad:** open the site in Safari -> Share -> *Add to Home Screen*.

This repository only contains the built app. It is generated from the main project (`mobile/` -> `npm run build:web`).
